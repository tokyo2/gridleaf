pdf-lib.min.js in this folder is pdf-lib 1.17.1, copied unchanged from the npm package
(https://www.npmjs.com/package/pdf-lib, dist/pdf-lib.min.js). It is self-hosted so the Gridleaf
Word Search Maker makes no requests to other websites. It is loaded only when a visitor downloads a PDF.
