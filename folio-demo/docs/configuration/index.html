Configuration

Every option in folio.config.ts, the one file that makes the site yours.

All site-wide settings live in src/folio.config.ts. Each option has a comment, and src/lib/types.ts lists every allowed value. Your editor will autocomplete them and warn about typos.

site

Option Example What it does
name 'Maple Studio' Header, page titles, structured data
tagline 'Calm digital tools' Footer line
description about 150 characters Default meta description
url 'https://shop.example.com' Canonical links, RSS, sitemap, sharing images
base '/' Set to '/repo-name' for a GitHub Pages project site
lang / locale 'en' / 'en-US' HTML language, price and date formats
author 'Sam Rivera' Default blog author
ogImage '/og-default.png' Sharing image for pages without their own image (1200 × 630, in public/)
demoMode true Shows sample testimonials and form previews. Set to false before launch.

After changing url or base, restart npm run dev.

theme

theme: {
  preset: 'sage',          // 'sage' | 'clay' | 'ocean'
  colors: { light: { accent: '#3D5A80' } },
  defaultMode: 'system',   // 'system' | 'light' | 'dark'
  showToggle: true,
},

See Colours and dark mode for details.

nav, socials and footer

nav is the main menu, in order. Links to /docs/, /pricing/ and /search/ are hidden automatically when those pages are switched off. socials are text links in the footer and on the contact page (any URL). footer.links are small links at the bottom, and footer.copyright supports {year}.

nav: [
  { label: 'Shop', href: '/products/' },
  { label: 'Blog', href: '/blog/' },
],

Internal links start with /. Folio adds the base for you, so they keep working on GitHub Pages.

shop

Option What it does
currency Default ISO code ('USD', 'EUR', 'GBP'…) for products without their own
buyLabel Default button text
freeLabel Shown instead of a price of 0
showCheckoutHost Adds “Secure checkout on gumroad.com” under buy buttons
newTab Opens checkout in a new tab (off by default, which converts better)
title, intro Heading and intro of the /products/ page
relatedTitle Heading above related products on product pages (an empty string hides them)
bundleTitle Heading above the products in a bundle

home

home.hero sets the headline, text, two buttons and the image: image is a file name inside src/assets/ (for example 'hero.png', or an empty string for a text-only hero) and imageAlt describes it for screen readers. home.titles holds the section headings. home.sections sets which sections appear on the home page, in order:

sections: ['featured', 'testimonials', 'pricing', 'about', 'posts', 'faq', 'newsletter'],

Remove a name to hide that section. A section also stays hidden while it has nothing to show (for example an empty testimonials.yaml). featuredCount and postsCount set how many cards appear.

blog, contact, newsletter, checkout, search, docs

  • blog: title, description and postsPerPage.
  • contact: your email, notes shown beside the form, and the optional form (Forms).
  • newsletter: provider-agnostic signup block (Forms).
  • checkout: optional Gumroad and Lemon Squeezy pop-up checkout (Products).
  • search.enabled: builds /search/ and shows the search button in the header.
  • docs.enabled: builds this docs section. false (the default in your download) removes its pages from the build, the sitemap, search and the menu.
  • pricing.enabled: builds /pricing/. false removes the page; the pricing block on the home page stays if 'pricing' is in home.sections.
  • footer.showCredit: true adds a small “Built with Folio” link in the footer. It is false in your download.
