Pages and navigation

Edit the About page, add new pages and change the menu.

The About page

src/pages/about.md is plain Markdown with a short front matter:

---
layout: ../layouts/PageLayout.astro
title: About the studio
description: A small, independent studio making calm, useful digital products.
eyebrow: About
---

Your story here.

Add a new page

Copy about.md, rename it (for example licence.md) and change the text. It is published at /licence/. Add it to the menu in folio.config.ts:

nav: [
  { label: 'Shop', href: '/products/' },
  { label: 'Licence', href: '/licence/' },
],

For pages that need components or custom layout, create an .astro file in src/pages/ and wrap it in BaseLayout:

---
import BaseLayout from '../layouts/BaseLayout.astro';
---

<BaseLayout title="Wholesale" description="Licences for teams and schools.">
  <div class="narrow prose">
    <h1>Wholesale</h1>
    <p>Write to us for volume licences.</p>
  </div>
</BaseLayout>

Links inside Markdown

Use relative links such as [contact](../contact/) in Markdown pages and posts. They keep working if you ever move the site into a sub-folder (for example on GitHub Pages).

Downloads and other files

Files in public/ are copied to the site as they are. public/files/free-sample.pdf is available at /files/free-sample.pdf.

Optional pages

The docs section, the pricing page and the search page live in src/optional/. They are added to the site only when docs.enabled, pricing.enabled or search.enabled is true in folio.config.ts, so switching one off also removes it from the sitemap and the menu.

The 404 page

src/pages/404.astro is the “page not found” page. Most hosts (Cloudflare Pages, Netlify, GitHub Pages) use it automatically.
