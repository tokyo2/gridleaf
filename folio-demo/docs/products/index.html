Products

Add a product with one Markdown file, connect any checkout, and organise products into categories.

Each product is a Markdown file in src/content/products/. The file name becomes the address: weekly-planner.md is published at /products/weekly-planner/.

A complete example

---
title: Quiet Week Planner
description: An undated weekly planner with room to think.
price: 12
compareAtPrice: 16
image: ../../assets/products/weekly-planner.png
imageAlt: Two pages of the planner showing a week laid out by day
buyUrl: https://YOURNAME.gumroad.com/l/planner
category: Planners
tags: [planner, printable]
featured: true
order: 10
details:
  - label: Format
    value: PDF, Letter + A4
  - label: Pages
    value: '64'
---

Everything below the front matter is the product description.
Use headings, lists and images as in any Markdown file.

Fields

Field Required Notes
title yes Product name
description yes One or two sentences (up to 240 characters): cards, search results, meta description
price yes A number. 0 shows “Free”
currency no ISO code; defaults to shop.currency
compareAtPrice no Shown struck through, for sales. Only show a previous price you actually charged
priceNote no Small text after the price, e.g. “pay what you want”
image / imageAlt yes Relative path to an image in src/assets/, plus a description for screen readers
buyUrl yes Any checkout link (see below)
buyLabel no Button text for this product only
category no Creates a category page and filter chip
tags no Used by search
details no Quick facts beside the buy button
featured no Featured products come first on the home page
order no Lower numbers come first (default 100)
draft no true hides the product from the live site
layout / includes no Bundles (Bundles)

If a field is missing or has the wrong type, npm run build stops with a message that names the file and field.

Checkout links

Folio does not handle payments itself; the buy button links to the checkout of the platform you already use:

Platform Typical link
Gumroad https://YOURNAME.gumroad.com/l/product
Payhip https://payhip.com/b/XXXXX
Lemon Squeezy https://YOURSTORE.lemonsqueezy.com/buy/...
Stripe Payment Links https://buy.stripe.com/...
Ko-fi https://ko-fi.com/s/...

Copy the share or checkout link from your platform and paste it as buyUrl.

Pop-up checkout (optional)

Gumroad and Lemon Squeezy offer a script that opens checkout in a pop-up over your page. Turn it on in folio.config.ts:

checkout: { gumroadOverlay: true, lemonSqueezyOverlay: false },

This loads the platform’s script on every page, so leave it off if you want the lightest pages. Folio loads https://gumroad.com/js/gumroad.js and https://app.lemonsqueezy.com/js/lemon.js (the address in Lemon Squeezy’s docs), and adds the lemonsqueezy-button class to Lemon Squeezy links. If your platform’s embed code shows a different address, follow the platform.

These are third-party scripts that may set cookies, so mention them in your privacy policy if you turn them on.

Images

Put product images in src/assets/products/ and use a relative path. Astro resizes them and serves modern formats with the right sizes for each screen. A 4:3 image of 1200 × 900 pixels or larger works best. The same image becomes the sharing image for the product page.

Categories

Give products a category and Folio adds a chip row to the shop page and a page per category at /products/category/<name>/.
