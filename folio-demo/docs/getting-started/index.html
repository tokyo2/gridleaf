Getting started

Install Folio and see it running on your computer in about five minutes.

Folio is a theme for Astro, a framework that turns Markdown files and components into a fast static website. You do not need to know Astro to use Folio: most changes happen in one config file and in Markdown files.

What you need

  • Node.js 22.23.4 or newer. Astro 7.4.2 and later require it; Node.js 24 also meets the requirement (Folio is tested on 22.23.4). Check with node --version. Get it from nodejs.org.
  • A code editor such as VS Code (free).
  • A terminal (Terminal on macOS, PowerShell or Windows Terminal on Windows).

Install

  1. Unzip the Folio download and open the folder in your editor.
  2. In a terminal inside that folder, install the dependencies:
npm install
  1. Start the development server:
npm run dev
  1. Open the address it prints (usually http://localhost:4321). The demo shop appears. Edits you save show up in the browser straight away.

The folders you will use

Folder or file What it holds
src/folio.config.ts Site name, URL, colours, navigation, socials, forms: start here
src/content/products/ One Markdown file per product
src/content/blog/ One Markdown or MDX file per post
src/content/docs/ These docs pages (shown when docs.enabled is true; reuse them for your own help centre)
src/content/*.yaml Testimonials, FAQ and pricing tiers
src/assets/ Images that Astro optimises (product and post images)
public/ Files copied as they are (favicon, social image, downloads)
src/pages/ One file per page or route; about.md is plain Markdown
src/optional/ Docs, pricing and search pages, built only when switched on in the config
src/styles/global.css All styles, with fonts and sizes at the top

Build the site

npm run build

This writes the finished website to dist/. Preview it with npm run preview, then follow Deploying to put it online.

Next steps

  1. Open src/folio.config.ts and change the site name, URL and email (Configuration).
  2. Replace the demo products with your own (Products).
  3. Before you publish, work through Before launch.
