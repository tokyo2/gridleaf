Updating and troubleshooting

Keep Folio and Astro up to date, and fix the most common build errors.

Updating Astro

Astro releases fixes often. To update within the same major version:

npm update
npm run build

We plan to release updates to Folio for new Astro major versions. CHANGELOG.md lists what changed in each release and which files to copy.

Updating Folio

New Folio versions are delivered through the same download you bought. Your own content lives in src/content/, src/assets/, src/pages/about.md and src/folio.config.ts, so keep those and copy the other files from the new version. If you changed components or styles, compare them before overwriting (your editor’s “compare files” feature helps).

Common problems

npm install warns about the Node.js version. Astro 7.4.2 and later need Node.js 22.23.4 or newer. Install it (Node.js 24 also meets the requirement) and run npm install again.

“products → my-product data does not match collection schema”. A product or post has a missing or misspelt field. The message names the file and the field, for example price: Expected type "number", received "string". Write numbers without quotes (price: 12), and put text in quotes when it contains a colon.

An image is not found. Image paths in front matter are relative to the Markdown file, for example ../../assets/products/my-image.png.

“Bundle … includes …, but there is no product file with that name”. Each id in includes must match a product file name without .md.

Links break on GitHub Pages. Set site.base to '/REPOSITORY', and use relative links (../contact/) inside Markdown.

The sitemap or sharing image shows the demo address. Set site.url to your real address and build again.

A form shows “Preview only”. Add the form’s action in folio.config.ts, or set demoMode: false to hide unconnected forms.

Getting help

Questions? Reply to your purchase receipt email, or use the contact or message link of the store where you bought Folio. Include the exact error message and your Node.js version (node --version). We aim to reply quickly.
