Features

Newsletter and contact forms

Connect any email provider or form service by pasting two values from its embed code.

Folio’s forms are plain HTML forms. They work with any service that gives you an “embed form” or an endpoint URL, and they add no JavaScript.

While site.demoMode is true, an unconnected form shows as a preview with a note. With demoMode: false, an unconnected form is hidden, so visitors never see a form that goes nowhere.

Newsletter signup

Open your provider’s embed code (often under “Forms”, “Embed” or “HTML form”) and copy:

  1. the action URL of the <form> tag, and
  2. the name of the email <input>.
newsletter: {
  enabled: true,
  title: 'New products, first',
  text: 'One short email when something new is out.',
  action: 'https://buttondown.com/api/emails/embed-subscribe/YOURNAME',
  method: 'POST',
  emailField: 'email',
  hiddenFields: {},
  buttonLabel: 'Subscribe',
  note: 'No spam. Unsubscribe with one click.',
  afterPosts: true,
},

Examples (always check against your own embed code, providers change them):

Provider action looks like emailField
Buttondown https://buttondown.com/api/emails/embed-subscribe/USERNAME email
Kit https://app.kit.com/forms/FORM_ID/subscriptions email_address
Mailchimp https://XXXX.us1.list-manage.com/subscribe/post?u=...&id=... EMAIL

If the embed code has other hidden inputs, add them to hiddenFields as { name: 'value' }. The block appears where 'newsletter' is listed in home.sections, and after every blog post when afterPosts is true.

Contact form

The contact page always shows your email address (if contact.email is set). Add a form service to show a form as well:

contact: {
  email: 'hello@example.com',
  intro: 'Questions about a product? Send a note.',
  form: {
    action: 'https://formspree.io/f/FORM_ID',
    method: 'POST',
    netlify: false,
    honeypot: '_gotcha',
    redirect: '',
  },
},

The form sends three fields: name, email and message.

Service action honeypot
Formspree https://formspree.io/f/FORM_ID _gotcha
FormSubmit https://formsubmit.co/you@example.com _honey
Basin https://usebasin.com/f/FORM_ID ask the service

honeypot adds a hidden field that people never fill in but spam bots do; use the field name your service checks. redirect adds a hidden _next field, which some services use as the “thank you” page.

Netlify Forms

When you host on Netlify, set netlify: true and leave action empty. Folio adds the attributes Netlify looks for. If Netlify asks, turn on form detection in your site’s Forms settings, then deploy again.
