Features

Colours, fonts and dark mode

Pick a preset, override any colour, check contrast and change fonts.

Presets

Folio has three colour presets, each with a light and a dark scheme:

Preset Feel
sage Calm green on warm paper (the demo)
clay Warm terracotta on cream
ocean Deep blue on cool grey 
theme: { preset: 'clay', colors: {}, defaultMode: 'system', showToggle: true },

Override single colours

Anything in theme.colors is merged on top of the preset:

colors: {
  light: { accent: '#3D5A80', link: '#3D5A80' },
  dark: { accent: '#9DB7D9', accentText: '#0E1A28', link: '#A9C3E3' },
},
Name Used for
bg, surface, tint Page background, cards, tinted sections
text, muted Main and secondary text
border, borderStrong Hairlines; form fields and outlines
accent, accentText Buttons and the text on them
link, focus Links and accent text; keyboard focus ring

Check contrast

Every preset meets WCAG 2.2 AA contrast. After changing colours, run:

npm run check:contrast

It checks 15 colour pairs in both schemes (body text, links, buttons, form borders and focus rings) and names any pair that is too faint.

Dark mode

  • defaultMode: 'system' follows the visitor’s device setting.
  • 'light' or 'dark' sets the first-visit default.
  • The header switch remembers the visitor’s choice. Hide it with showToggle: false.

The theme is applied before the page paints, so there is no flash of the wrong colours.

Fonts

Folio uses DM Serif Display for headings and Inter for text. Both are open-source (SIL Open Font License) and served from your own site, with no font CDN.

To change them, install another font from Fontsource, import it at the top of src/layouts/BaseLayout.astro, and change the variables at the top of src/styles/global.css:

--font-body: 'Inter Variable', system-ui, sans-serif;
--font-display: 'DM Serif Display', Georgia, serif;

The same block sets the corner radius, page width and spacing.
