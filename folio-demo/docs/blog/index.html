Blog posts

Write posts in Markdown or MDX, with tags, RSS, reading time and pagination built in.

Posts live in src/content/blog/. The file name becomes the address: launch-checklist.md is published at /blog/launch-checklist/.

---
title: A simple launch checklist
description: Twelve small checks that catch most launch-day problems.
pubDate: 2026-09-30
updatedDate: 2026-10-05
heroImage: ../../assets/blog/launch-checklist.png
heroAlt: Calm blue circles on a pale background
tags: [launch, selling]
author: Sam Rivera
draft: false
---

Your post starts here.
Field Required Notes
title, description yes Description is used on cards, in RSS and as the meta description
pubDate yes YYYY-MM-DD
updatedDate no Shows “Updated” and is used in structured data
heroImage, heroAlt no Image in src/assets/
tags no Each tag gets a page at /blog/tags/<tag>/
author no Defaults to site.author
draft no true hides the post from the live site (it still shows in npm run dev)

MDX: components inside posts

Rename a post to .mdx to use components. Folio includes a Callout:

import Callout from '../../components/Callout.astro';

<Callout title="Good to know">This is highlighted.</Callout>

What you get automatically

  • Reading time, previous and next links, and tag links on every post.
  • Pagination: blog.postsPerPage posts per page (/blog/, /blog/2/…).
  • An RSS feed at /rss.xml.
  • BlogPosting structured data and Open Graph tags.
  • Code blocks highlighted in both light and dark mode.
