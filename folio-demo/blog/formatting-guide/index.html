Formatting guide: what Markdown looks like here

A reference post that shows every common Markdown element in the Folio style, from headings and lists to tables and code.

By Folio DemoSeptember 12, 20261 min read

Keep this post as a reference while you write, then delete it (or set draft: true in its front matter) before you launch.

Headings

Use ## for sections and ### for sub-sections. The page title is the only first-level heading.

A third-level heading

Short paragraphs are easier to read on a phone. Two to four sentences is a good length.
