FAQ

How do I print them?

Download the files, then print at home, at a local print shop or with any online photo lab.

Which sizes can I print?

Every common frame size from 4x6 up to 24x36 in, and A5 to A1. The size guide tells you which file to use for each frame.

Is a print or frame included?

No. It's a digital download, so nothing is shipped. Colors may vary slightly between screens and printers.

Can I sell the prints?

No. The files are for personal use in your own home.
